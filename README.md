# GUESTED_ONE ANTIVIRUS

**Ваша безопасность. Ваш контроль. Ваша система.**

Guested_One Antivirus — самостоятельный проект антивирусного программного обеспечения от **Первого_Гостевого**.

Программа предоставляет инструменты локальной проверки файлов, анализа подозрительных объектов, управления карантином и диагностики системы.

---

## О проекте

Guested_Antivirus — это настольное приложение для обеспечения безопасности, включающее графический интерфейс, интерфейс командной строки и дополнительные системные утилиты.

Проект разработан для предоставления пользователям удобного локального просмотра файлов и базовых инструментов, связанных с безопасностью.

## Функции

- **File Scanner** — локальная проверка файлов и каталогов.
- **Smart Scan** — автоматический режим проверки.
- **Deep Scan** — углублённая проверка содержимого файлов.
- **Fast Scan** — быстрая проверка по именам и расширениям.
- **Quarantine** — помещение подозрительных файлов в карантин.
- **Reports** — создание отчётов о сканировании.
- **Activity Log** — журнал действий программы.
- **Plugin Support** — поддержка локальных Python-плагинов.
- **G1 CMD** — отдельный интерфейс командной строки.
- **System Tools** — дополнительные диагностические инструменты.

## Установка

1. Откройте раздел **Релизы** этого репозитория.
2. Загрузите последнюю версию установщика.
3. Запустите `Guested_One_Antivirus_Setup.exe`.
4. Следуйте инструкциям по установке.
5. Запустите Guested_Antivirus из меню «Пуск» или в строке поиска.

## Важное замечание

Антивирус Guested_One использует эвристический метод обнаружения. Результаты обнаружения могут включать ложные срабатывания.

Приложение не является сертифицированной антивирусной платформой и не гарантирует обнаружение каждой угрозы. Оно не должно заменять Windows Security или другие авторитетные решения в области безопасности.

Всегда проявляйте осторожность при работе с подозрительными файлами.
